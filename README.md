# Heal

> Software engineers don't always test their code. But when they do, they do it in production.

Don't let your coding agents do the same. Let them heal your codebase before production.

**Heal** builds the verification harness your repo is missing: the tools a coding agent needs to see for itself whether its change works.

- **Before production**, it can run the real product locally, in seconds, without the costly or remote parts.
- **While the product runs**, what happens is recorded in a form the agent can read.
- **After production**, what really happened is checked, and can be replayed locally.

Your coding agents will still test in production. But on purpose.
