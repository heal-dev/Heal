# Security policy

## Supported versions

Only the latest release gets security fixes.

## Report a vulnerability

Do not open a public issue.

- Preferred: [report it in private on GitHub](https://github.com/heal-dev/Heal/security/advisories/new).
- Or write to `security@heal.dev`.

Please include a description, the steps to reproduce, and a fix or a way to reduce the risk if you know one.

## What to expect

- We confirm that we received the report within 3 business days.
- For a high severity issue, we give a plan or a fix within 30 days.
- We agree with you on the date of public disclosure.

## Scope

In scope: the source code in this repository, the published packages, the CI workflows, and the supply chain of the published packages.

Out of scope: vulnerabilities in dependencies that are already public, social engineering, and findings that need privileged access to a maintainer's machine or account.

## Safe harbour

We will not take legal action against research done in good faith that follows this policy.
